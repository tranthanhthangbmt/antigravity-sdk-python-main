Chào bạn, để chạy hệ thống web này (gồm phần Frontend dùng React và Backend dùng FastAPI), bạn cần mở 2 terminal (cửa sổ dòng lệnh) riêng biệt để chạy song song. Dưới đây là hướng dẫn chi tiết từng bước:

1. Chạy Backend (FastAPI - Python)
Mở một cửa sổ terminal mới (bạn có thể mở trong VS Code) và thực hiện các bước sau:

Bước 1: Di chuyển vào thư mục backend

powershell
cd d:\MY_CODE\Antigravity_SDK1\antigravity-sdk-python-main\translateEbooks\WebApp\backend
Bước 2: Cài đặt các thư viện cần thiết (nếu bạn chưa cài) Hệ thống sử dụng FastAPI, Uvicorn, thư viện của Google Gemini và PyMuPDF. Bạn chạy lệnh:

powershell
pip install fastapi uvicorn google-generativeai pymupdf websockets
Bước 3: Chạy server backend Sau khi đã cài xong, bạn gõ lệnh sau để khởi động server:

powershell
python main.py
Server sẽ chạy ở địa chỉ: http://localhost:8000

2. Chạy Frontend (React + Vite)
Mở một cửa sổ terminal thứ hai và thực hiện:

Bước 1: Di chuyển vào thư mục frontend

powershell
cd d:\MY_CODE\Antigravity_SDK1\antigravity-sdk-python-main\translateEbooks\WebApp\frontend
Bước 2: Cài đặt các gói npm (nếu chạy lần đầu)

powershell
npm install
Bước 3: Khởi động giao diện web

powershell
npm run dev
Sau khi chạy thành công, terminal sẽ hiện ra một đường link (thường là http://localhost:5173). Bạn bấm chuột vào link đó hoặc copy dán vào trình duyệt web để mở ứng dụng.

3. Cách sử dụng (Theo file hướng dẫn)
Như trong file howToRun.txt của bạn đã ghi, hệ thống dịch này yêu cầu một API Key của Google AI Studio để có thể hoạt động.

Bạn truy cập Google AI Studio (API Key).
Tạo hoặc copy một API Key hiện có (Nó là một đoạn mã dài bắt đầu bằng AIzaSy...).
Mở trang web ứng dụng ở bước 2, dán đoạn mã Key vừa copy vào ô "Antigravity API Key" trên thanh tìm kiếm của trang web.
Bấm Start Translation để hệ thống bắt đầu dịch sách.
Bạn hãy thử chạy theo các bước trên nhé! Nếu gặp lỗi thiếu thư viện hay lỗi ở bước nào thì hãy nhắn lại để tôi hỗ trợ thêm.
-----------------------------------

Để lấy API Key chạy hệ thống dịch tự động (sử dụng mô hình AI của Google), bạn có thể lấy hoàn toàn miễn phí tại Google AI Studio.

Dưới đây là các bước lấy Key:

Bạn truy cập vào trang quản lý API của Google: https://aistudio.google.com/app/apikey (yêu cầu đăng nhập bằng tài khoản Google/Gmail của bạn).
Nhấn vào nút màu xanh "Create API Key".
Chọn một Project hiện có hoặc tạo mới.
Màn hình sẽ hiện ra một chuỗi ký tự dài (ví dụ: AIzaSyB...). Bạn hãy copy đoạn mã này.
Quay lại giao diện Web App của chúng ta, dán đoạn mã vừa copy vào ô "Antigravity API Key" trên thanh tìm kiếm và bấm Start Translation.
Hệ thống backend của chúng ta sẽ sử dụng Key này để kết nối tới bộ não LLM và tiến hành quá trình phân tích/dịch tự động tài liệu của bạn!
